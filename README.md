## 最近在做 · 装材明白

**装修材料看不懂，报价也想算明白。**

[装材明白](https://flftech.com/) 是一个装修材料 AI 鉴别助手，从照片和报价表入手，帮助整理选材依据、混淆风险与费用明细。

- **拍照识材**：上传材料照片，查看候选材料、可见依据和补拍建议。
- **报价核算**：上传详细报价表，对照商家最初承诺的价格，核算落地价与差额。
- **材料档案**：从板材、地板、石材、涂料开始，了解容易混淆的材料和现场核验方法。
